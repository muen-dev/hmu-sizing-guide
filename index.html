Adding sizes to your products

Every screen you need is already in the admin — this walks through it with pictures. The one part only you can decide is Step 1. Steps 2–3 take about two minutes. Step 4 is the slow part, and we can do it for you.

How to read the pictures. Each screen below is drawn from the live admin — same menus, same fields, same wording as you'll see. The amber box marks the thing to look at; the black label says what to do with it. Product names and size values in them are examples, not your shop's data.
1

Decide: one size list, or two?

You mentioned sizes XS–XL and numeric 0–16. Before creating anything, choose whether they share one list or sit in two separate ones.

One listTwo lists
What you createOne attribute called Size, holding all 14 valuesTwo attributes: Size (XS–XL) and Kids size (0–16)
What a shopper seesAll 14 buttons on every productOnly the sizes that piece actually comes in
Shop filteringOne filter rowTwo filter rows
Best ifThe numeric sizes are smaller versions of the same adult lineKids' pieces are their own thing, sold separately
Pick before you create. The code and the variant-defining setting cannot be changed afterward, and deleting a value a product already uses is refused. If you'd rather not start and stop, tell me which way you're leaning and I'll set it up.

The practical risk of one list: someone looking at an adult gown sees 0 2 4 6 8… next to XS S M L XL and has to work out which apply. If any of the collection is children's wear, two lists avoids that entirely.

B. Three fields, three ticks. Variant-defining is the one that matters: unticked, no product can ever be sold in more than one size. "Variant" is what we call each sellable version of a piece — the M and the L of one trouser are two variants of it.

If Size already appears in the Attributes list, skip creating it and open its values instead (Step 3).

C. The Values panel. Value is what shoppers read — type it exactly as you want it on the shop. Code fills itself in from the Value; leave it alone, it's internal.

Standard sizes, added in this order (the ▲▼ arrows set display order and the shop follows it):

XS   S   M   L   XL

Numeric sizes:

0   2   4   6   8   10   12   14   16

Odd numbers aren't listed — say so if you want them and we'll add them. If you chose two lists in Step 1, create Kids size the same way first, then put these nine numbers under it instead of under Size.

About the bare numbers. A button reading 8 tells a shopper little — they'd have to already know what a size 8 means for a child. You can write them however you like:
8 (2 yrs)   8 · US kids   8 (approx 2y)
Whatever goes in the Value field is exactly what shows on the shop; the internal code stays short either way. Pairing each with an age is the usual way brands do it — but it's your call, you know the customer.
Removing a value later is possible, but any existing option already using it keeps it — removal only stops it being offered on new ones.

D. Generate variants builds all sizes at once. Pick the size chips, set a starting price, and write the stock code with {size} where the size goes — HMU-SHIRT-{size} gives HMU-SHIRT-XS, HMU-SHIRT-S, and so on automatically.

Generated options are not sellable yet. The screen says this plainly. Until you give each one a quantity (or mark it made-to-order), shoppers can't buy it. Budget a few minutes per product — this is the step people miss.

One size at a time instead? Click Add variant: Name is the size (M), SKU is that size's stock code (required, cannot be changed later), Price required, Compare-at price optional and shows struck through. A Size dropdown appears under those fields once Steps 2–3 are done — if it's missing, go back and check them.

5

Check it worked

Open that product on the live shop. You should see the size buttons, and one must be chosen before adding to bag. If they don't appear, the usual cause is the variant having no stock set — Step 4's warning.

✱

For "one of a kind" pieces

Most of the collection is genuinely unique — one copy, no size choice. Those stay exactly as they are: one variant, no size. Only add sizes to pieces actually made in a range.

If a piece is one-of-a-kind but you still want its size recorded (so it's searchable and shows on a spec sheet), add a value called One size in Step 3 and assign it. That records the size without offering a choice.

→

Or let us do the slow part

Adding those values is quick — two minutes. Applying sizes across 50 styles by hand is not: roughly an hour of clicking, and easy to end up with stock codes that don't match each other.

Do Steps 2 and 3 yourself (that sets the vocabulary, and it lets us work from the same list), then send us the sizing chart — which styles come in which sizes, and prices per size if they differ — and we'll load Step 4 in one pass and check every product against your chart before it goes live.
